# 259.12 CORRECTIONAL INMATES; NAME CHANGES; LIMITED.
During an inmate's confinement in a correctional facility, as defined in section 241.021, subdivision 1i, an inmate may request a name change under section 259.10 only once and may proceed in forma pauperis only when the failure to allow the name change would infringe on a constitutional right of an inmate.
History: 1995 c 16 s 1; 2024 c 85 s 78
