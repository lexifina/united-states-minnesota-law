# 473.804 HOUSEHOLD HAZARDOUS WASTE MANAGEMENT.
By June 30, 1992, each metropolitan county shall develop and implement a permanent program to manage household hazardous waste. Each program must include at least quarterly collection of wastes. Each program must be consistent with the metropolitan policy plan and must be described as part of each county's solid waste plan revision as required under section 473.803, subdivision 1.
History: 1Sp1989 c 1 art 20 s 29; 1995 c 247 art 2 s 35; 2023 c 60 art 3 s 37
