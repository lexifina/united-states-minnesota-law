# 16A.61 CERTIFICATE MONEY TO GENERAL FUND.
The commissioner shall transfer money credited to a fund set up for paying off certificates of indebtedness to the general fund when the purpose of the certificates is accomplished.
History: Ex1961 c 88 s 57; 1969 c 399 s 3; Ex1971 c 3 s 56; 1973 c 492 s 14; 1984 c 628 art 2 s 1
