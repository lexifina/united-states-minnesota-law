# 332.41 APPEALS.
Appeal from a denial, suspension, revocation, or censure of a license or registration must be made according to chapter 14.
History: 1969 c 766 s 11; 1973 c 720 s 54 subd 2; 1979 c 144 s 6; 1980 c 516 s 2; 1983 c 289 s 114 subd 1; 1984 c 655 art 1 s 92; 2001 c 208 s 24; 2004 c 208 s 7
