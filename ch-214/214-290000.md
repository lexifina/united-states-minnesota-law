# 214.29 PROGRAM REQUIRED.
Each health-related licensing board shall either conduct a health professionals service program under sections 214.31 to 214.37 or contract for a diversion program under section 214.28.
History: 2000 c 284 s 9; 2014 c 291 art 4 s 51; 2024 c 122 art 2 s 7; 2024 c 127 art 64 s 7
