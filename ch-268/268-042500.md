# 268.0425 ELECTRONIC TRANSACTION PRESUMPTION.
If any electronic transaction is done under this chapter using an identification number or code assigned an employer by the commissioner, the transaction is presumed as done by that employer unless a preponderance of the available evidence shows that it was not done by that employer.
History: 2004 c 183 s 15,86; 1Sp2019 c 7 art 8 s 7
