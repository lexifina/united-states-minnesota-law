# 518C.702 APPLICABILITY.
Sections 518C.701 to 518C.713 apply only to a support proceeding under the convention. In such a proceeding, if a provision of sections 518C.701 to 518C.713 is inconsistent with sections 518C.101 to 518C.616, sections 518C.701 to 518C.713 control.
History: 2014 c 189 s 56,73; 2015 c 71 art 1 s 119
