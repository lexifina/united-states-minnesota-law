# 128.02 COUNTY COMMISSIONER DISTRICT IS ELECTION DISTRICT.
Note: MS 1957 [Repealed, Ex1959 c 71 art 8 s 26]
In Independent School District No. 166, each county commissioner district is an election district. One school board member is elected from each election district.
History: (2780-12) 1929 c 9 s 5; 1941 c 169 art 4 s 25; 1989 c 220 s 1
