# 156.10 UNLAWFUL PRACTICE WITHOUT LICENSE OR PERMIT; GROSS MISDEMEANOR.
It is a gross misdemeanor for any person to practice veterinary medicine in the state without having first secured a veterinary license or temporary permit, as provided in this chapter.
History: (5851-10) 1937 c 119 s 10; 1976 c 285 s 10; 1996 c 415 s 17; 1999 c 231 s 160
