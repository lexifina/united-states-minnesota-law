# 628.22 INDICTMENT FOR CRIMINAL DEFAMATION.
An indictment for criminal defamation need not set forth any extrinsic facts for the purpose of showing the application to the party defamed of the defamatory matter on which the indictment is founded, but it shall be sufficient to state generally that the same was published concerning the party defamed, and the fact that it was so published shall be established on the trial.
History: (10651) RL s 5309; 1965 c 45 s 70; 1986 c 444
