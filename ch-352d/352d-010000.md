# 352D.01 ESTABLISHMENT.
There is hereby established within the Minnesota State Retirement System a retirement program for certain public employees to be known as the Minnesota unclassified employees retirement program. The program must be administered by the Minnesota State Retirement System.
History: 1971 c 604 s 1; 1973 c 624 s 1; 1986 c 458 s 5; 1Sp2005 c 8 art 10 s 30
