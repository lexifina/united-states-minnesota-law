# 471.79 ENFORCEMENT.
The district court may, at the suit of any taxpayer, enforce the performance by any governing body, board, commission, officer, or agent of any municipality of any action which it is directed to perform by sections 471.71 to 471.83, to the full extent necessary to carry out the purpose thereof.
History: 1943 c 526 s 7; 1951 c 63 s 9; 1986 c 444
