# 176.091 MINOR EMPLOYEES.
Except as provided in section 176.092, a minor employee has the same power to enter into a contract, make election of remedy, make any settlement, and receive compensation as an adult employee.
History: 1953 c 755 s 9; 1957 c 781 s 1; 1973 c 388 s 17; 1975 c 271 s 6; 1975 c 359 23; 1976 c 134 s 78; 1993 c 194 s 3
