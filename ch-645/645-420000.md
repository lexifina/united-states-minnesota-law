<p>
    <b> 645.42 Effect of separate repeals on code provisions </b>
 <b> enacted at the same session.  </b>
</p><p>
    When a law repeals any provision of a law incorporated into 
 a code adopted at the same session of the legislature, the law 
 repealing the provisions so incorporated into the code shall be 
 construed to effect a repeal of the corresponding provision of 
 the code.  
</p><p>
