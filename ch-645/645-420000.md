        <h1 class="shn">645.42 EFFECT OF SEPARATE REPEALS ON CODE PROVISIONS ENACTED AT SAME SESSION.</h1>
        <p>When a law repeals any provision of a law incorporated into a code adopted at the same session of the legislature, the law repealing the provisions so incorporated into the code shall be construed to effect a repeal of the corresponding provision of the code.</p>
