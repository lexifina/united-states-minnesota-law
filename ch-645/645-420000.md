      <div class="xtend"><a id="stat..0"></a><b>645.42 EFFECT OF SEPARATE REPEALS ON CODE PROVISIONS ENACTED AT </b><br>
         		<b>THE SAME SESSION.</b><br>
         		When a law repeals any provision of a law incorporated into a code adopted at the same <br>
         		session of the legislature, the law repealing the provisions so incorporated into the code shall be <br>
         		construed to effect a repeal of the corresponding provision of the code.<br>
         		<b>History: </b><i><a href="/laws/?doctype=Chapter&amp;year=1941&amp;type=0&amp;id=492">1941 c 492 s 42</a><br>
         		</i>
