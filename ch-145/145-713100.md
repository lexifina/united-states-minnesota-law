# 145.7131 EXCEPTION TO EYEGLASS PRESCRIPTION EXPIRATION.
Notwithstanding any practice to the contrary, in an emergency situation or in the case of lost glasses, an optometrist or physician may authorize a new pair of prescription eyeglasses using the prescription from the old lenses or the last prescription available.
History: 2014 c 291 art 10 s 1; 2017 c 59 s 4; 2018 c 170 s 4
