# 3.974 DISTRIBUTION OF WRITTEN REPORT.
For each audit, evaluation, or other review completed, the legislative auditor shall provide a written report to the organization or individual audited, evaluated, or reviewed; the Legislative Reference Library; and the Legislative Audit Commission.
History: (3286-10) 1939 c 431 art 4 s 3; 1973 c 492 s 29; 1986 c 444; 1988 c 469 art 1 s 1; 1999 c 99 s 3
